GWAS approaches for multiallelic loci

How to test loci with three or more alleles without throwing away biological information—or quietly fitting the wrong model.

Short answer

Yes. The most general solution is to represent a locus with K alleles by K − 1 allele-count or dosage variables, fit them jointly, and test all K − 1 coefficients with a site-level omnibus test. Follow that with allele-specific estimates for interpretation.

This page concerns a multiallelic genetic locus, not a multivariate phenotype and not a test aggregating many separate SNPs. Those are different problems despite the similar names.

The core model

Suppose a diploid locus has alleles A0, A1, …, AK−1. Choose A0 as the reference and let Gij be the number—or imputed dosage—of allele Aj carried by individual i. Fit all non-reference alleles together:

g(E[Yi]) = α + β1Gi1 + … + βK−1Gi,K−1 + Xiγ

The link g is identity for a quantitative trait and logit for a binary trait; survival and count links can be substituted. X contains ancestry, batch, environment, sex, or other covariates. A mixed model can add a kinship random effect.

Do not regress one alternate allele at a time while ignoring the others. At a single diploid site, allele counts sum to two. Jiang et al. showed that naïve separate regression can bias allele effects; the alleles should be modeled jointly.

The primary site-level null is H0: β1 = … = βK−1 = 0, tested by a Wald, likelihood-ratio, or score test with up to K − 1 degrees of freedom. Each βj estimates the change per additional copy of Aj relative to A0, conditional on the other allele dosages.

Six useful approaches

Default

1. Joint allelic regression + omnibus test

Fit K − 1 allele dosages jointly. Use the omnibus P value to discover loci and the individual coefficients to describe which alleles differ. Flexible, interpretable, and appropriate when alleles may have different directions.

Simple alternative

2. Collapsed non-reference test

Replace all alternate alleles with one “any alternate” dosage. It uses one degree of freedom and may gain power when all alternate alleles have similar effects. It loses information and can cancel or conceal heterogeneous effects.

Ordered biology

3. Length or copy-number trend

For STRs, VNTRs, or CNVs, regress phenotype on total repeat length, mean allele length, summed copy number, or another prespecified function. This is powerful for a monotonic dose response but misses threshold, nonlinear, and allele-sequence effects.

Few common genotypes

4. Genotypic categorical test

Treat unordered diploid genotypes as categories rather than assuming additive allele effects. This captures dominance and allele-pair interactions, but the number of genotype classes grows to K(K+1)/2 and sparse cells quickly become a problem.

Structured loci

5. Haplotype or functional-state test

For HLA or linked multiallelic markers, test classical alleles, amino-acid residues, or inferred haplotypes with multi-df likelihood-ratio tests, then perform conditional analyses. This can map association closer to functional states than nearby biallelic tags.

Rare alleles

6. Burden / variance-component test

For many rare alleles in a gene or region, burden tests pool effects under a shared-direction assumption; SKAT-type tests allow heterogeneous directions and magnitudes; SKAT-O adapts between them. This is a set-level question, not a substitute for a common multiallelic site test.

A defensible analysis workflow

  1. Preserve the locus. Keep REF and every ALT allele, stable allele labels, phase if relevant, and allele-specific dosage uncertainty. Splitting a VCF record for storage is fine; forgetting that the records belong to one locus is not.
  2. Perform multiallelic QC. Inspect per-allele frequency and missingness, allele balance, read depth, batch effects, call quality, and an appropriate multiallelic exact Hardy–Weinberg test. For STRs, also inspect stutter and length-dependent call error.
  3. Control structure and relatedness. Include ancestry covariates or use a mixed model/kinship term. In ecological samples, add sampling locality, cohort, family, and major environmental design variables when justified.
  4. Choose one primary encoding in advance. Joint categorical allele effects are the safest general default. Choose a length trend or collapsed test only when biology supports its constraint.
  5. Test the locus once, then interpret alleles. Use a site-level omnibus P value for discovery. Report allele frequencies, conditional effect estimates, standard errors, confidence intervals, and the reference allele.
  6. Handle sparse alleles explicitly. Predefine a minimum allele count, pool only biologically defensible alleles, or use score/permutation/Firth or set-based methods. Label post hoc pooling as exploratory.
  7. Calibrate multiplicity. Correct over the effective family of tested loci/models. If several encodings are primary, account for them; if one is primary and others are sensitivity analyses, say so.
  8. Replicate the same contrast. Harmonize every allele—not merely “effect” and “other”—and preserve the coefficient covariance matrix for multiallelic meta-analysis.

Implementation notes

PLINK 2

Current PLINK 2 documentation states that --glm can use one genotype/dosage column per nonmajor allele at a multiallelic variant. Add multiallelic to permit such variants and omit-ref when ALT-based rather than nonmajor-allele coding is required.

plink2 --pfile cohort \
  --pheno traits.tsv --pheno-name trait \
  --covar covariates.tsv --covar-name age,sex,PC1-PC10 \
  --glm hide-covar multiallelic omit-ref firth-fallback \
  --out trait_multiallelic

PLINK’s ordinary output is allele-specific. Confirm that your selected version/output provides the exact site-level joint test you need; otherwise construct the joint Wald/LRT/score test from an engine that returns the full coefficient covariance, or use dedicated software.

Direct regression in R

For a tri-allelic site A/C/T with A as reference, include both alternate-allele dosages in the same model:

# quantitative phenotype
fit0 <- lm(y ~ age + sex + PC1 + PC2, data = d)
fit1 <- lm(y ~ dose_C + dose_T + age + sex + PC1 + PC2, data = d)
anova(fit0, fit1)  # partial F test for the 2-df site-level contrast

# binary phenotype
fit0 <- glm(case ~ age + sex + PC1 + PC2,
            family = binomial(), data = d)
fit1 <- glm(case ~ dose_C + dose_T + age + sex + PC1 + PC2,
            family = binomial(), data = d)
anova(fit0, fit1, test = "LRT")

For related samples, replace these with an appropriate linear or generalized linear mixed model. For sequence-study association and meta-analysis of multiallelic sites, Jiang et al. implemented joint modeling in RVTESTS and multiallelic summary-statistic meta-analysis in RAREMETAL. For length-based tandem-repeat GWAS, associaTR provides a dedicated workflow.

Common failure modes

  • Independent ALT-vs-rest regressions: they do not condition on the other alleles and can bias effects.
  • Collapsing by convenience: “non-reference” is a modeling assumption, not a neutral data-cleaning step.
  • Using the usual biallelic HWE test: genotype expectations and sparse-cell behavior differ at multiallelic loci; use a multiallelic procedure.
  • Interpreting the omnibus P value as an allele effect: it only says at least one modeled contrast differs.
  • Ignoring genotype uncertainty: hard calls can be especially damaging for rare ALT alleles, HLA imputations, and repeat lengths.
  • Reference-allele drift across cohorts: meta-analysis requires identical allele definitions and covariance-aware joint statistics.
  • Too many genotype categories: a fully genotypic model becomes unstable rapidly as K grows.
  • Assuming diploidy: the K − 1 dosage framework generalizes conceptually, but polyploid genotype uncertainty, dosage, inheritance, and HWE require polyploid-aware software.
